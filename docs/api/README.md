# API reference

`inspectIssueTree(files)` accepts a record of relative file paths to Markdown text. Its report includes records, diagnostics, summaries and the unblocked frontier. Invalid tickets leave records empty. Filesystem discovery, Git identity and persistence belong to the caller.
